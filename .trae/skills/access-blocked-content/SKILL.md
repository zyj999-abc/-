# Access Blocked Content

## Description

在目标网页被验证码、登录墙、环境异常、地区限制、反爬策略或动态渲染阻挡时，使用一套合规、保守、可复用的流程来尽可能恢复信息，并明确区分已确认事实、侧面佐证和未知部分。

这个 Skill 的目标不是绕过安全机制，而是：

- 优先尝试合法公开访问路径
- 在失败时寻找公开镜像、转载、缓存和官方二级来源
- 在无法验证时明确说明限制
- 及时向用户索要截图、正文或补充材料

## When to Use

在以下情况使用：

- 直接抓取网页时只拿到标题、摘要或截断内容
- 页面跳转到 CAPTCHA、登录页、环境异常页、区域限制页
- 浏览器可打开链接，但正文无法稳定读取
- 需要基于某篇文章、公告、活动页或文档给用户建议，但原文不可直接获取

不要在以下情况使用：

- 页面内容已经完整可读
- 用户已经提供了正文或足够清晰的截图
- 任务需要突破权限、绕过验证或访问受限账户内容

## Success Criteria

成功完成任务应满足以下至少一项：

1. 获取到完整正文并能引用其中关键信息
2. 无法获取全文，但能从多个公开来源恢复关键规则或事实
3. 无法恢复关键内容时，明确说明已尝试的方法、失败原因和下一步所需材料

## Output Contract

输出必须分成以下几类，不得混淆：

- `已确认`：来自可直接访问原文或高可信公开来源的信息
- `高概率推断`：基于官方文档、公开摘要、上下文交叉验证得到的推断
- `未确认`：无法验证、需要用户补充的部分
- `下一步`：建议用户提供的最小补充材料

如果无法拿到完整正文，必须明确写出：

- 哪些方法已经尝试过
- 哪一步被阻断
- 当前还能给出的建议范围

## Instructions

1. 先直接访问目标链接。
   - 先尝试标准抓取。
   - 若可用浏览器工具，先查看标签页，再打开页面，再读取页面结构。

2. 判断失败类型。
   - 内容截断
   - CAPTCHA 或环境异常
   - 登录墙
   - 动态渲染为空
   - 地区限制
   - 站点不可达

3. 针对失败类型执行补救路径。
   - 内容截断：尝试浏览器快照、站内其他入口、官方博客或官方文档对应页面
   - CAPTCHA 或环境异常：尝试标题搜索、唯一链接 ID 搜索、官方站内搜索、可信转载、缓存或镜像
   - 登录墙：寻找公开公告、帮助中心、新闻稿、社区转载
   - 动态渲染为空：尝试浏览器视图、等待加载、查找接口或文本替代来源
   - 地区限制：寻找相同内容的国际站、文档站、博客站、发布说明

4. 搜索替代来源时，优先级如下。
   - 原站点的其他公开入口
   - 官方博客、官方文档、官方帮助中心
   - 官方社媒或官方聚合页
   - 高可信媒体、社区转载、搜索摘要
   - 用户提供的截图或正文

5. 交叉验证。
   - 至少用两个独立线索验证关键事实，例如时间、规则、奖项、评审标准、操作步骤
   - 若只有单一线索，不得把它表述为确定事实

6. 在任何时候都不要伪造已读内容。
   - 如果只看到标题，就只说确认了标题
   - 如果只拿到摘要，就只说确认了摘要
   - 不要把常见活动规则套写成该文章原文

7. 当外部路径全部失败时，立刻向用户索要最小必要材料。
   - 优先索要：正文复制文本
   - 其次索要：关键段落截图
   - 再次索要：规则区块，例如评审标准、时间、奖项、提交流程

8. 取得用户补充材料后，重新输出。
   - 先提炼规则
   - 再给建议
   - 最后明确哪些内容来自用户提供材料

## Recommended Workflow

### Phase 1: Direct Access

- 读取链接
- 判断是否完整
- 记录失败类型

### Phase 2: Public Recovery

- 用标题搜索
- 用 URL 唯一串搜索
- 查原站博客、文档、新闻和活动页
- 查高可信转载

### Phase 3: Evidence Grading

- 列出已确认事实
- 列出高概率推断
- 列出未确认部分

### Phase 4: User Escalation

- 如果关键内容仍缺失，向用户请求正文或截图
- 指明最需要哪几段

## Failure Strategy

- 如果页面被验证码阻断：明确说明无法直接读取正文，不得假装已获取全文
- 如果只找到单一转载摘要：标为高概率信息，不标为已确认
- 如果搜索没有收录：停止继续猜测，改为请求用户提供材料
- 如果用户要基于未验证内容做决策：先提示风险，再给条件式建议

## Templates

### Template: Limited Access Report

```md
已确认
- 已确认链接标题为：
- 已确认页面被以下机制阻断：

高概率推断
- 根据以下公开线索，较大概率可判断：

未确认
- 以下关键信息尚未获得原文验证：

下一步
- 请提供以下任一材料：
```

### Template: User Request

```md
我已经确认目标链接存在，但正文被站点风控拦截，当前不能可靠读取全文。

为了继续给你准确建议，请发我以下任一内容：
- 文章正文复制文本
- 规则区块截图
- 你最关心的几段原文
```

## Notes

- 这个 Skill 解决的是“受限访问下的可靠信息恢复”，不是“绕过站点验证”
- 首要原则是诚实、保守、可验证
